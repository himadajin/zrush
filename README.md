# zrush

入力に合わせて補完候補をプロンプトに表示する zsh 補完プラグイン。

- 曖昧補完に対応 (`gti` → `git`、`dcs` → `docs`)。
- シンタックスハイライトに対応。
- 入力中の内容でコマンド履歴を絞り込める。

## Getting started

macOS / Linux、zsh 5.8 以上に対応しています。
ビルドには cargoが必要です。

- [インストール](docs/user/install.md)
- [使い方・キー操作](docs/user/usage.md)
- [設定](docs/user/configuration.md)

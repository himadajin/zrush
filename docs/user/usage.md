# 使い方

## 基本

文字を打つと候補一覧がプロンプト下に自動表示される。そのまま打ち続ければ一覧は追従する。
あいまい入力にも対応しており、`gti` → `git`、`dcs` → `docs` のような誤字・部分列からでも
候補に到達できる。

zrush が入力を勝手に書き換えることはない。`~` は展開されず、
確定操作をするまでバッファは打った通りに保たれる。

候補を確定(挿入)した後も補完は継続する。`git branch -d ` でブランチを確定すれば
続けて残りのブランチが、ディレクトリを確定すればその中身が自動で表示される。

## キー操作(既定)

| キー | 動作 |
|---|---|
| ↓ / ctrl-n | 選択を開始 / 次の候補へ |
| ↑ / ctrl-p | 前の候補へ(先頭候補でさらに押すと選択解除)/ 選択していなければ履歴メニューを開く |
| ← → / ctrl-b / ctrl-f | 隣の列へ(選択中のみ) |
| Enter | 選択候補を**挿入**(実行はもう一度 Enter) |
| ctrl-g | 一覧を閉じる(バッファはそのまま) |
| Tab | `[insert].tab` の設定に従う(既定は選択メニュー開始) |

選択していない間、これらのキーはおおむね通常の zsh の動きのまま(← → はカーソル移動など)。
例外は 3 つ:

- ↑ / ctrl-p は履歴メニューを開く(下記)。
- 一覧表示中の ↓ / ctrl-n は選択を開始する
  (複数行バッファの行移動・履歴の戻りが必要な場面ではそちらを優先)。
- 一覧表示中の ctrl-g は選択していなくても一覧を閉じる。

一覧が表示されていないときの ↓ / ctrl-n と ctrl-g は zrush 適用前の動作へ戻る。

## 履歴メニュー

↑(または ctrl-p)を押すと、いま打っている内容に一致する履歴だけを絞り込んだ一覧が出る。
空のまま押せば全履歴が出る。ここでも入力が勝手に書き換わることはない。

| キー | 動作 |
|---|---|
| ↑ / ctrl-p | 1 つ古い履歴へ |
| ↓ / ctrl-n | 1 つ新しい履歴へ(最新の位置でもう一度押すと一覧を閉じる) |
| ← / ctrl-b | 一致したうち最も新しい履歴へ |
| → / ctrl-f | 表示中の最も古い履歴へ |
| Enter | 選んだ履歴で行全体を置き換えて**挿入**(実行はもう一度 Enter) |
| Tab | Enter と同じく選んだ履歴を確定 |
| ctrl-g | 一覧を閉じる(入力はそのまま) |

- 一覧は 1 列でプロンプトから上へ伸び、最下行が一致したうちで最も新しい履歴になる。
  開いた時点ではこの最下行が選択され、↑ で画面上の古い履歴へ移動する。
- 選んで動かしている間は入力に触らないので、閉じれば打ちかけの入力がそのまま残る。
- 一致する履歴が 1 件もなければ一覧は出ない(入力は変わらない)。
- 履歴メニュー中に文字を打ったりカーソルを動かしたりすると一覧は閉じ、通常の補完表示に戻る。
- 複数行のコマンドは 1 行に潰して表示されるが、挿入されるのは改行を含む原文。
- 各行の先頭には zsh の履歴イベント番号が表示される。番号は表示専用で、確定時には挿入されない。
- すでに素の履歴移動で過去のコマンドを遡っている最中は、↑ ↓ はそのまま履歴移動として働く。
- 遡る履歴の件数は `[history].limit`、ctrl-p を素の履歴移動に戻す方法は `configuration.md`。

## Tab

既定(`menu`)では Tab で選択メニューに入る。`configuration.md` の設定で
「先頭候補を即挿入」(`insert`)や「共通部分を挿入、伸びなければ先頭候補」
(`common-prefix`)に変えられる。

候補がまだ出ていないタイミングで Tab を押した場合は、収集を前倒しして
到着したときに設定どおりの動作をする。

## うまく動かないとき

- `command not found: compdef` が出る → compinit より前に zrush や他ツールの補完設定を
  source している。`.zshrc` の順序を見直す(`install.md`)。
- 起動時に「protocol version」の警告が出る → `git pull` 後の rebuild 忘れ。
  `cargo build --release` を実行する。
- 設定の警告が出る → メッセージに「どのキーが・なぜ・どの値に戻したか」が出ている。
  該当行を修正すれば次のプロンプトから反映される。

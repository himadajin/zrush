# notes-dogfooding: M5 日常投入の記録

zsh-autocomplete を無効化し zrush に切り替えた日常利用(mac + Linux)の記録。
「使用をためらう問題」がゼロになった時点で M5 完了(specs / user docs へ昇格)。

記入ルール:

- 気になった挙動は 1 件 1 エントリで「日付 / 環境 / 再現手順 or 状況 / 期待と実際」を書く。
  解決したら対処(コミット)を追記して `[解決]` を付ける。
- 判断に迷う「好みの問題」も書く(設定項目化・固定値変更の材料になる)。

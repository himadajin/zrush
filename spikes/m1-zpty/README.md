# M1 spike: zpty による compsys 候補収集の技術検証

`docs/internal/plans/001-prototype/plan.md` の M1 に対応する検証用スクリプト群。
結論・計測値は `docs/internal/plans/001-prototype/notes-zpty.md` に記録する。

このディレクトリは検証用であり、成立した方式は M3 以降で `zsh/zrush.zsh` に移植する。

## 検証チェックリスト(plan.md M1 より)

### 広げクエリでの候補の正しさ

- [ ] ファイル名補完で候補が取れる
- [ ] コマンド位置の空語で全コマンド名が取れる(`gti` の広げ結果)
- [ ] `docs/inte` の広げ結果(`docs/`)で `docs/` 配下が取れる
- [ ] `--verbso` の広げ結果(`--`)でオプション集合が取れる
- [ ] git サブコマンド補完で候補が取れる

### compadd フックの網羅性(必須)

- [ ] `-O`/`-A` 付き呼び出し(マッチテスト用)を候補として数えない
- [ ] `-P`/`-S`/`-p`/`-s`/`-i`/`-I` 込みの挿入文字列の再構成が
      「置換範囲 = 削った末尾領域」モデルと整合する
- [ ] 表示文字列と挿入文字列を区別できる

### compadd フックの網羅性(あれば良い・合否に含めない)

- [ ] 説明文(`-d`)の取得
- [ ] グループ(`-J`/`-V`/`-X`)の取得

### pty 出力の清浄化

- [ ] `stty -onlcr` 等の設定
- [ ] NUL 番兵による結果のフレーミング
- [ ] `zpty -b` + `zle -F` での部分読みの再組み立て
- [ ] 改行を含むファイル名の往復

### キャンセルと後始末

- [ ] リクエストごとの zpty 作り直し+`zpty -d` によるキャンセル
- [ ] 世代番号による stale 結果の破棄
- [ ] 数秒かかる補完関数を模擬したキャンセルの実証(非ブロック原則)
- [ ] `zshexit` での掃除
- [ ] 再帰防止ガード(`ZRUSH_INTERNAL=1`)の動作

### 計測

- [ ] 1 リクエストの端到端レイテンシ(fork〜候補受信完了)
- [ ] 大量候補での入力非ブロック(数万件ディレクトリ、空語での全コマンド名)
- [ ] 連打時の挙動
- [ ] 実際の .zshrc + 実サイズの履歴を積んだシェルでの計測

### その他

- [ ] `~` を含む入力が展開されずに扱えること

# M1 spike: zpty による compsys 候補収集の技術検証

`docs/internal/plans/001-prototype/plan.md` の M1 に対応する検証用スクリプト群。
結論・計測値は `docs/internal/plans/001-prototype/notes-zpty.md` に記録している。

このディレクトリは検証用であり、成立した方式は M3 以降で `zsh/zrush.zsh` に移植する。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `01-fd-inherit.zsh` | pipe fd 継承の単体検証(単独実行、6 テスト) |
| `02-capture-v0.zsh` | 捕獲 v0: 候補語のみの最小往復(比較用に温存) |
| `03-capture-v1.zsh` | 捕獲 v1: メタデータ込みレコード・広げ規則適用・キャンセル対応(本命) |
| `04-widen.zsh` | 広げ規則(セグメント保持規則)の純関数 `zrush_widen` |
| `driver.zsh` | 回帰テストドライバ(59 テスト)。隔離ホスト(zsh -df)で全機能を検証 |
| `driver-bench.zsh` | 計測ドライバ。実 ~/.zshrc + 実履歴ホストを含む(通常は実行不要) |
| `rc/minimal.zshrc` | 隔離ホスト用の最小 rc |
| `rc/test-completers.zsh` | 決定的な合成補完(メタデータ・遅延・異常系の再現用) |

実行方法:

```sh
zsh 01-fd-inherit.zsh                      # 期待: PASS=6 FAIL=0
zsh driver.zsh <playground-dir>            # 期待: PASS=59 FAIL=0
zsh driver-bench.zsh <fixtures-root-dir>   # 計測(実 .zshrc を読む。履歴には書き込まない)
```

## 検証チェックリスト(plan.md M1 より。全項目の判定は独立監査済み)

### 広げクエリでの候補の正しさ

- [x] ファイル名補完で候補が取れる
- [x] コマンド位置の空語で全コマンド名が取れる(`gti` の広げ結果。4,199 件)
- [x] `docs/inte` の広げ結果(`docs/`)で `docs/` 配下が取れる
- [x] `--verbso` の広げ結果(`--`)でオプション集合が取れる
- [x] git サブコマンド補完で候補が取れる(141 件)

### compadd フックの網羅性(必須)

- [x] `-O`/`-A` 付き呼び出し(マッチテスト用)を候補として数えない
- [x] `-P`/`-S`/`-p`/`-s`/`-i`/`-I` 込みの挿入文字列の再構成が
      置換範囲モデル(末尾置換+接頭辞不一致時の語全体拡張)と整合する
      (素の compsys の実挿入と突き合わせて全ケース一致)
- [x] 表示文字列と挿入文字列を区別できる

### compadd フックの網羅性(あれば良い・合否に含めない)

- [x] 説明文(`-d`)の取得
- [ ] グループの取得は部分的(`-J` は取得可、`-X`/`-V` は検証ケースでは値が流れず。記録のみ)

### データ搬出路の清浄性

当初想定(pty stdout + stty 清浄化 + NUL 番兵)は、検証の結果
**候補データを pty に流さない構成**(継承 pipe fd + EOF 終端)に置き換えて成立。
stty 清浄化は不要になった。

- [x] NUL 区切りレコードのフレーミング(異常終端は `unterminated-payload` として検出)
- [x] pipe の部分読み再組み立て(`zle -F -w` + sysread。1MiB/3MB ペイロードで実証)
- [x] 改行を含むファイル名の往復

### キャンセルと後始末

- [x] リクエストごとの zpty 作り直し+キャンセル
      (`zpty -d` の HUP だけでは外部コマンド待ちの fork を殺せないため、
      worker の pid 自己申告 + `kill -INT -pgid` → `zpty -d` の順で行う)
- [x] stale 結果の破棄(旧 rfd の `zle -F` 解除 + close による物理遮断。
      世代番号は zpty 名の一意化にのみ使用)
- [x] 数秒かかる補完関数を模擬したキャンセルの実証(非ブロック原則)
- [x] `zshexit` での掃除
- [x] 再帰防止ガード(`ZRUSH_INTERNAL=1`)の動作

### 計測

- [x] 1 リクエストの端到端レイテンシ(fork〜候補受信完了)
- [x] 大量候補での入力非ブロック(3 万件ディレクトリ、空語での全コマンド名)
- [x] 連打時の挙動(結果は最後の 1 件のみ・プロセス蓄積なし)
- [x] 実際の .zshrc + 実サイズの履歴を積んだシェルでの計測
      (制約: zsh-autocomplete 共存ホストではコマンド位置の空語収集が 0 件になる。
      実環境での空語計測は M5 で ZAC を外したあとに再実施する)

### その他
